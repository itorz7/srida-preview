OCR ภาษาไทย อ่านเอกสารด้วย AI ในเครื่อง

แปลงเอกสารสแกน ใบเสร็จ และแบบฟอร์มภาษาไทยเป็นข้อความและตาราง ที่ค้นหาได้และส่งต่อให้ระบบอื่นใช้ได้ โดยภาพเอกสารไม่ต้องออกนอกองค์กร

ปรึกษาทีมงานดูโมเดลที่ใช้ได้

ใช้ทำอะไรได้บ้าง

  • เอกสารสแกนที่ค้นหาได้

    แปลงเอกสารเก่าและหนังสือที่สแกนไว้เป็นข้อความ ค้นหาด้วยคำได้ทันที

  • ใบเสร็จและแบบฟอร์ม

    ดึงตัวเลข ชื่อ และวันที่จากใบเสร็จหรือแบบฟอร์มเข้าระบบ ลดการพิมพ์ซ้ำ

  • ตารางในเอกสาร

    อ่านตารางออกมาเป็นข้อมูลที่นำไปใช้ต่อได้ เช่น Typhoon OCR 2 ส่งตารางออกมาเป็น HTML

  • ลายมือภาษาไทย

    บางโมเดล เช่น OpenThai 2.0 ผู้พัฒนาระบุว่าอ่านเอกสารและลายมือภาษาไทยได้

  • ถามตอบจากภาพ

    โมเดลอ่านภาพ (vision-language) ตอบคำถามเกี่ยวกับภาพหรือแผนภูมิได้

  • ส่งต่อให้ LLM

    อ่านเอกสารแล้วให้ LLM สรุปหรือตรวจข้อมูลต่อ ทุกขั้นตอนอยู่ในเครื่อง

ข้อมูลจากหน้าโมเดลทางการบน Hugging Face, GitHub, ollama.com และเว็บไซต์ของผู้พัฒนา ชื่อโมเดลเป็นของผู้พัฒนาแต่ละราย

ลองอ่านเอกสารในเครื่อง

เริ่มจาก EasyOCR ที่ติดตั้งง่าย แล้วค่อยขยับไปโมเดลที่ฝึกมาเพื่อเอกสารไทยอย่าง Typhoon OCR 2

Python
import easyocr

reader = easyocr.Reader(["th", "en"])
for line in reader.readtext("receipt.jpg", detail=0):
    print(line)

ติดตั้งด้วย pip install easyocr · Typhoon OCR 2 ติดตั้งด้วย pip install typhoon-ocr2 และมีไฟล์ GGUF ทางการสำหรับรันในเครื่อง

คำถามเกี่ยวกับ OCR ภาษาไทย

OCR ภาษาไทยอ่านสระและวรรณยุกต์ถูกไหม

โมเดลรุ่นใหม่ที่ฝึกกับเอกสารไทยโดยเฉพาะ เช่น Typhoon OCR และ Pathumma Vision ถูกพัฒนามาเพื่องานนี้ แต่ผลยังขึ้นกับความคมชัดของภาพสแกน ควรทดสอบกับเอกสารจริงขององค์กรก่อน

อ่านตารางได้ไหม

ได้ Typhoon OCR 2 แยกหัวข้อ ย่อหน้า และตาราง โดยตารางออกมาเป็น HTML ที่นำไปใช้ต่อได้

ต้องใช้เครื่องแรงแค่ไหน

โมเดล OCR รุ่นเล็ก เช่น Typhoon OCR 2 ขนาด 2B มีไฟล์ GGUF ราว 1.3 GB (ไม่รวมไฟล์ mmproj) รันบนเครื่องทั่วไปได้ ส่วนโมเดลอ่านภาพขนาดใหญ่อย่าง OpenThai 2.0 ขนาด 27B ต้องใช้เครื่องที่มีหน่วยความจำมาก
