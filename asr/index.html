ถอดเสียงภาษาไทย ด้วย AI ที่รันในเครื่อง

แปลงเสียงประชุม สายสนทนา และคลิปวิดีโอเป็นข้อความภาษาไทย ทั้งแบบถอดจากไฟล์และแบบสด โดยไฟล์เสียงอยู่ในเครื่องขององค์กรตลอดทาง

ปรึกษาทีมงานดูโมเดลที่ใช้ได้

ใช้ทำอะไรได้บ้าง

  • ถอดเสียงการประชุม

    ได้ข้อความพร้อมเวลา แล้วส่งให้ LLM สรุปเป็นรายงานการประชุมต่อได้

  • สายสนทนาคอลเซ็นเตอร์

    ถอดเสียงสายทั้งหมดเพื่อค้นหาและตรวจคุณภาพบริการ โดยไม่ส่งเสียงของลูกค้าออกไปข้างนอก

  • คำบรรยายใต้คลิป

    ทำซับไตเติลภาษาไทยให้คลิปสอนงานหรือวิดีโอประชาสัมพันธ์

  • พิมพ์ด้วยเสียงแบบสด

    ใช้โมเดลแบบสตรีมมิงที่หน่วงต่ำ แปลงเสียงพูดเป็นข้อความได้ทันที

  • คำเฉพาะขององค์กร

    บางโมเดลรับรายชื่อคำเฉพาะ เช่น ชื่อคนหรือชื่อสินค้า เพื่อช่วยให้ถอดคำเหล่านั้นได้ถูกต้องขึ้น

  • ต่อกับการแปลภาษา

    ถอดเสียงภาษาไทยแล้วส่งต่อให้ระบบแปลเป็นภาษาอังกฤษ

ลองถอดเสียงไฟล์แรก

ตัวอย่างนี้ใช้ Thonburian Whisper ผ่านไลบรารี transformers ถอดไฟล์เสียงในเครื่อง (ต้องติดตั้ง Python และ ffmpeg ก่อน)

Python
from transformers import pipeline

asr = pipeline(
    "automatic-speech-recognition",
    model="biodatlab/whisper-th-large-v3-combined",
    chunk_length_s=30,
)
print(asr("meeting.wav")["text"])

ติดตั้งไลบรารีด้วย pip install transformers torch · อยากได้แบบสดและเบาพอสำหรับซีพียู ลอง pip install typhoon-asr ของ Typhoon ASR Real-time

คำถามเกี่ยวกับ ถอดเสียงภาษาไทย

ถอดเสียงภาษาไทยแม่นแค่ไหน

ขึ้นกับคุณภาพเสียง สำเนียง เสียงรบกวน และคำเฉพาะในงาน ผู้พัฒนาแต่ละรายรายงานผลทดสอบบนชุดข้อมูลของตัวเอง ซึ่งอาจไม่ตรงกับเสียงในองค์กรของคุณ เราจึงลองกับไฟล์ตัวอย่างของคุณก่อนเลือกโมเดล

ถอดเสียงแบบสดได้ไหม

ได้ มีโมเดลแบบสตรีมมิงสำหรับงานสด เช่น Typhoon ASR Real-time ซึ่งผู้พัฒนาระบุว่ารันบนซีพียูทั่วไปได้ และ OpenThai 2.0 ASR Streaming ที่หน่วงต่ำ

ต้องส่งไฟล์เสียงออกไปข้างนอกไหม

ไม่ต้อง ไฟล์เสียงประมวลผลบนเครื่องที่ติดตั้งโมเดล จึงเหมาะกับเสียงที่มีข้อมูลส่วนบุคคล เช่น สายสนทนากับลูกค้า
