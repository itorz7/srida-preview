ทำไมต้องถอดเสียงในเครื่อง

เสียงประชุม สายสนทนากับลูกค้า และบันทึกของแพทย์ มักมีข้อมูลส่วนบุคคลหรือข้อมูลลับ การถอดเสียงในเครื่องขององค์กรทำให้ไฟล์เสียงไม่ต้องส่งออกไปข้างนอก และเมื่อต้องถอดเสียงจำนวนมาก ก็ไม่มีค่าบริการตามจำนวนนาที

ถอดจากไฟล์ หรือถอดแบบสด

ถอดจากไฟล์ เหมาะกับไฟล์ประชุมหรือคลิปที่บันทึกไว้แล้ว โมเดลตระกูล Whisper อย่าง Thonburian Whisper, Pathumma Whisper และ Typhoon Whisper ใช้งานแบบนี้ได้ดี

ถอดแบบสด เหมาะกับการพิมพ์ด้วยเสียงหรือคำบรรยายสด ต้องใช้โมเดลแบบสตรีมมิงที่มีความหน่วงต่ำ เช่น Typhoon ASR Real-time, Pathumma STT FastConformer และ OpenThai 2.0 ASR Streaming

ลองถอดเสียงไฟล์แรก

ตัวอย่างนี้ใช้ Thonburian Whisper ผ่านไลบรารี transformers ต้องติดตั้ง Python และ ffmpeg ในเครื่องก่อน แล้วติดตั้งไลบรารีด้วย pip install transformers torch

Python
from transformers import pipeline

asr = pipeline(
    "automatic-speech-recognition",
    model="biodatlab/whisper-th-large-v3-combined",
    chunk_length_s=30,
)
print(asr("meeting.wav")["text"])

รุ่น large-v3 มีขนาดใหญ่ ถ้าเครื่องไม่มีการ์ดจอจะช้า ลองรุ่นเล็กกว่าในตระกูลเดียวกัน หรือใช้ Typhoon ASR Real-time ที่ติดตั้งด้วย pip install typhoon-asr

ต่อยอด: สรุปการประชุมด้วย LLM

เมื่อได้ข้อความจากการถอดเสียงแล้ว ส่งต่อให้ LLM ภาษาไทยในเครื่องช่วยสรุปเป็นรายงานการประชุมและรายการงานที่ต้องทำได้ เช่น รัน Typhoon 2.5 ผ่าน Ollama แล้วส่งข้อความที่ถอดได้เข้าไปพร้อมคำสั่งให้สรุป ทุกขั้นตอนอยู่ในเครื่องเดียวกัน ดูวิธีติดตั้งได้ที่ Ollama ภาษาไทย
