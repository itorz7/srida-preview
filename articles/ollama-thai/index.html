Ollama ภาษาไทย: ติดตั้งและรัน LLM ภาษาไทยในเครื่อง

Ollama คืออะไร

Ollama เป็นโปรแกรมฟรีสำหรับดาวน์โหลดและรันโมเดลภาษาในเครื่อง ใช้ได้ทั้ง Linux, macOS และ Windows สั่ง ollama run ตามด้วยชื่อโมเดล โปรแกรมจะดาวน์โหลดโมเดลและเปิดหน้าแชตในเทอร์มินัลให้

Ollama มีทั้งโมเดลที่รันในเครื่องและโมเดลบนคลาวด์ของ Ollama หากต้องการให้ข้อมูลอยู่เฉพาะในเครื่อง ให้เลือกรุ่นสำหรับรันในเครื่อง

ติดตั้ง Ollama

Linux และ macOS

$ curl -fsSL https://ollama.com/install.sh | sh

บน Mac ดาวน์โหลดแอปจาก ollama.com/download ได้เช่นกัน

Windows

เปิด PowerShell แล้วรันคำสั่งนี้ หรือดาวน์โหลดตัวติดตั้ง OllamaSetup.exe จากหน้าเว็บของ Ollama

$ irm https://ollama.com/install.ps1 | iex

เลือกโมเดลภาษาไทยให้พอดีกับเครื่อง

เริ่มจากรุ่นเล็กก่อน ถ้าเครื่องไหวค่อยขยับขึ้น ขนาดไฟล์ด้านล่างมาจาก ollama.com และไฟล์ GGUF ทางการของผู้พัฒนา

โมเดลขนาดไฟล์คำสั่งเหมาะกับ
Sailor2 1B1.1 GBollama run sailor2:1bเครื่องไม่มีการ์ดจอ RAM 8 GB
Typhoon 2.5 4B2.5 GBollama run scb10x/typhoon2.5-qwen3-4bโน้ตบุ๊กทั่วไป
OpenThai 1.5 7B4.7 GBollama run openthai/openthai-1.5-7bหน้าโมเดลแนะนำ RAM ราว 8 GB
Typhoon 2.1 12B7.3 GBollama run scb10x/typhoon2.1-gemma3-12bการ์ดจอหรือ Mac หน่วยความจำ 16 GB
OpenThai 2.0 27B16.8 GBollama run openthai/openthai2.0-qwen3.8-27bหน่วยความจำ 24 GB ขึ้นไป

รันและคุยภาษาไทย

รันคำสั่งด้านล่าง ครั้งแรกจะดาวน์โหลดโมเดลก่อน เมื่อเสร็จแล้วพิมพ์คำถามภาษาไทยได้ทันที พิมพ์ /bye เพื่อออก

$ ollama run scb10x/typhoon2.5-qwen3-4b

รันไฟล์ GGUF จาก Hugging Face

โมเดลภาษาไทยบางตัวยังไม่มีบนคลังของ Ollama แต่มีไฟล์ GGUF บน Hugging Face รันได้ตรง ๆ ด้วยรูปแบบคำสั่งนี้ โดยแทนชื่อผู้ใช้และชื่อคลังของโมเดล ถ้าคลังมีไฟล์ Q4_K_M ระบบจะเลือกให้เอง หรือระบุเองต่อท้ายได้ เช่น :Q8_0

$ ollama run hf.co/{ชื่อผู้ใช้}/{ชื่อคลัง}

ที่มา: เอกสารของ Hugging Face เรื่องการใช้กับ Ollama

เรียกใช้ผ่าน API

ระหว่างที่ Ollama ทำงาน จะเปิด API ที่ http://localhost:11434 ให้โปรแกรมอื่นในเครื่องเรียกใช้ได้ ตัวอย่างนี้ส่งคำถามภาษาไทยหนึ่งข้อ

Shell
curl http://localhost:11434/api/chat -d '{
  "model": "scb10x/typhoon2.5-qwen3-4b",
  "messages": [{"role": "user", "content": "สรุปข้อดีของ Local AI สั้น ๆ"}],
  "stream": false
}'

ปัญหาที่พบบ่อย

  • ตอบช้ามาก ลองรุ่นที่เล็กลง หรือใช้เครื่องที่มีการ์ดจอ
  • หน่วยความจำไม่พอ เลือกรุ่นที่ไฟล์เล็กกว่าหน่วยความจำที่มีพอสมควร
  • ตอบเป็นภาษาอังกฤษปน เลือกโมเดลที่ฝึกฝนมาเพื่อภาษาไทย และบอกในคำถามว่าให้ตอบเป็นภาษาไทย

อยากได้ระบบแชตที่ทั้งทีมใช้ร่วมกันพร้อมเอกสารขององค์กร ดูหน้า LLM ภาษาไทยสำหรับองค์กร

อ่านต่อ

  • Local AI คืออะไร และรัน AI ในเครื่องได้อย่างไร
  • ถอดเสียงภาษาไทยในเครื่อง ด้วยโมเดลเปิดที่ดาวน์โหลดได้
  • บทความทั้งหมด

เล่าโจทย์ของคุณ แล้วเราช่วยเลือก AI ที่พอดีกับงาน

  • อยากให้ AI ช่วยงานอะไร เช่น ถอดเสียงประชุม หรือถามตอบเอกสาร
  • ข้อมูลเป็นแบบไหน และอยู่ที่ใดบ้าง
  • มีเครื่องหรือเซิร์ฟเวอร์อะไรอยู่แล้ว
ช่องทางติดต่อเปิดเร็ว ๆ นี้ ดูสินค้าและบริการ
