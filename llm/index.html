LLM ภาษาไทย ที่รันในองค์กรของคุณ

ให้ AI อ่านเอกสาร ตอบคำถาม และช่วยเขียนงานภาษาไทย โดยโมเดลทำงานบนเครื่องหรือเซิร์ฟเวอร์ขององค์กร เอกสารไม่ต้องอัปโหลดขึ้นคลาวด์ของใคร

ปรึกษาทีมงานดูโมเดลที่ใช้ได้

ใช้ทำอะไรได้บ้าง

  • ถามตอบจากเอกสารองค์กร

    เชื่อม LLM เข้ากับคู่มือ ระเบียบ และเอกสารภายใน (RAG) ให้พนักงานถามเป็นภาษาไทย แล้วได้คำตอบพร้อมบอกว่ามาจากเอกสารไหน

  • สรุปรายงานและบันทึกประชุม

    ย่อเอกสารยาวเป็นประเด็นสำคัญ หรือดึงรายการงานที่ต้องทำต่อออกมาให้

  • ร่างหนังสือและอีเมล

    ร่างหนังสือ อีเมล และข้อความตอบลูกค้าตามรูปแบบขององค์กร ให้คนตรวจทานก่อนส่ง

  • จัดหมวดและดึงข้อมูล

    อ่านข้อความจำนวนมาก เช่น ความเห็นของลูกค้า แล้วจัดหมวดหรือดึงข้อมูลที่ต้องการออกมาเป็นตาราง

  • เป็น API ให้ระบบเดิม

    เปิดโมเดลเป็น API ภายในองค์กร ให้ระบบที่ใช้อยู่เรียกใช้ได้ เช่น llama.cpp มีเซิร์ฟเวอร์แบบเดียวกับ API ของ OpenAI

  • ทำงานต่อจาก AI ด้านอื่น

    รับข้อความจากการถอดเสียงหรือ OCR มาสรุปต่อ ทุกขั้นตอนอยู่ในเครื่องเดียวกัน

$ ollama run scb10x/typhoon2.5-qwen3-4b

ใช้ Windows: ติดตั้งด้วย irm https://ollama.com/install.ps1 | iex ใน PowerShell · ทีละขั้นอยู่ในบทความ Ollama ภาษาไทย

ง่ายที่สุด · Linux, macOS, Windows

  • Ollama มีโมเดลแบบคลาวด์ด้วย หากต้องการให้ข้อมูลอยู่เฉพาะในเครื่อง ให้เลือกรุ่นสำหรับรันในเครื่อง

เครื่องแค่ไหนรันรุ่นไหนได้

หลักคร่าว ๆ คือ ไฟล์โมเดลแบบ 4-bit (Q4_K_M) มีขนาดราว 0.6 GB ต่อโมเดล 1B ควรเผื่อหน่วยความจำไว้อีก 1–2 GB และเผื่อเพิ่มเติมตามความยาวบทสนทนา

การ์ดจอนับจาก VRAM · Mac ชิป M นับจากหน่วยความจำรวม (unified memory) · ถ้าไม่มีการ์ดจอ นับจาก RAM แต่จะตอบช้ากว่า

ขนาดไฟล์มาจากไฟล์ GGUF ทางการ ส่วนหน่วยความจำที่ควรมีเป็นค่าประมาณ

คำถามเกี่ยวกับ LLM ภาษาไทย

LLM ภาษาไทยตัวไหนดีที่สุด

ไม่มีโมเดลใดดีที่สุดสำหรับทุกงาน ขึ้นกับลักษณะงาน สเปกเครื่อง และสัญญาอนุญาต เช่น Typhoon 2.5 ขนาด 4B รันบนโน้ตบุ๊กได้ ส่วน OpenThai 2.0 ขนาด 27B ต้องใช้เครื่องที่มีหน่วยความจำราว 20–24 GB เราจึงทดสอบหลายตัวกับข้อมูลของคุณก่อนเลือก

ใช้ LLM ในเครื่องกับเอกสารลับได้ไหม

ได้ เมื่อโมเดลรันบนเครื่องขององค์กร เอกสารและคำถามจะประมวลผลอยู่ในเครื่องนั้น ควรตั้งสิทธิ์การเข้าถึงให้เหมาะสม และเลือกใช้รุ่นสำหรับรันในเครื่อง เพราะบางโปรแกรม เช่น Ollama มีโมเดลแบบคลาวด์ให้เลือกด้วย

ต้องมีการ์ดจอไหม

ไม่จำเป็นสำหรับโมเดลเล็ก 1B–4B ที่รันบนซีพียูได้แต่จะตอบช้ากว่า ถ้ามีผู้ใช้หลายคนพร้อมกันหรือใช้โมเดลใหญ่ ควรมีการ์ดจอ หรือใช้ Mac ชิป M ที่มีหน่วยความจำมากพอ
